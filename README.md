# ФинПульс — лендинг о личных финансах

Одностраничный лендинг вымышленного сервиса **ФинПульс**: все счета в одной картине,
умные бюджеты, цели, инвестиции и аналитика расходов.

Сайт собран на чистом HTML, CSS и JavaScript — без сборки, фреймворков и зависимостей.

**Демо:** https://finpulse-landing.vercel.app

![Стек](https://img.shields.io/badge/HTML-CSS-JS-37e9a8?style=flat-square)
![Без зависимостей](https://img.shields.io/badge/dependencies-0-37e9a8?style=flat-square)

## Что внутри

- **Hero с дашбордом** — «живой» интерфейс приложения: график баланса, метрики,
  последние операции, плавающие карточки целей и кэшбэка.
- **Возможности** — bento-сетка с реальными UI-мокапами (счета, бюджеты, портфель, цели).
- **Как это работает** — три шага подключения.
- **Калькулятор накоплений** — сложный процент с капитализацией, пересчёт на лету.
- **Тарифы** — переключатель «месяц / год» с пересчётом цен.
- **Отзывы, FAQ-аккордеон, финальный CTA с валидацией формы.**
- Анимации появления, счётчики, наклон карточки за курсором, бегущая строка курсов.
- Адаптив от 360 px, поддержка `prefers-reduced-motion`, клавиатурной навигации,
  `aria-*`-атрибутов и skip-link.

## Структура

```
index.html            — разметка страницы
assets/styles.css     — стили (дизайн-токены в :root)
assets/app.js         — вся интерактивность
assets/favicon.svg    — иконка
site.webmanifest      — PWA-манифест
vercel.json           — заголовки безопасности и кэширование
robots.txt
```

## Локальный запуск

Достаточно открыть `index.html` в браузере. Для корректной работы относительных путей
и манифеста удобнее поднять статический сервер:

```bash
npx serve .
# или
python3 -m http.server 3000
```

## Деплой

Сайт собран как статический: сборки нет, публикуется корень репозитория
(`outputDirectory: "."`, build и install — no-op команды, чтобы Vercel не искал `package.json`).
Файл `vercel.json` добавляет заголовки безопасности и кэш для статики.

Обновить продакшен после изменений:

```bash
vercel --prod
```

или кнопкой **Redeploy** в панели Vercel.
