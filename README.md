# StoryCraft AI — студия сториз и постов с персональным ИИ-агентом

Веб-приложение для создания сториз (9:16), постов и каруселей для Instagram, Telegram, LinkedIn и Threads.
В центре продукта — **настраиваемый ИИ-агент**, который пишет тексты вашим голосом: с вашей нишей, лексикой,
фирменными фразами, запрещёнными словами и стилем призыва к действию.

## Возможности

### 🎬 Студия сториз
- Генерация **серии слайдов 9:16** по 4 сюжетным формулам: разрушение мифа, путь героя, лид-магнит, закулисье.
- Живой предпросмотр в макете телефона — с прогресс-барами, шапкой профиля и футером соцсети.
- Интерактивные стикеры прямо на слайде: опрос, ползунок, вопрос, реакция (кликабельные в превью).
- **Режиссёрские подсказки** для каждого слайда: что говорить, какой ракурс и эмоцию использовать при съёмке.
- Редактор слайда: текст, акцентная плашка, тема оформления (6 палитр), выравнивание, роль в драматургии.
- Быстрая доработка ИИ: «сделать острее», «сократить», «вставить фирменное словечко», «мягче».
- Копирование полного сценария съёмки в буфер и экспорт каждого слайда в **PNG (HD)**.

### ✍️ Студия постов
- Адаптация под платформу: Telegram (с inline-кнопкой), Instagram, LinkedIn, Threads.
- Форматы: одиночный пост, **карусель** (5 карточек с экспортом в PNG), форматированный Telegram-пост.
- Генератор **5 вирусных хуков** под тему.
- Готовый промпт для генерации иллюстрации (Midjourney / DALL·E / Flux).
- Копирование в один клик: чистый текст или Markdown.
- Предпросмотр в реальном макете выбранной соцсети.

### 🤖 ИИ-агент под вас
- Несколько архетипов из коробки (эксперт-разработчик, лайфстайл, B2B, психолог) + создание своего.
- Tone of Voice: 8 тональностей, уровень провокации (1–5), плотность эмодзи.
- Мужской / женский род — агент согласует глаголы в прошедшем времени.
- База знаний: личные факты и кейсы, фирменные фразы, **стоп-слова** (никогда не используются).
- Воронка: кодовое слово для Direct, стиль CTA, ссылки и кнопки.
- Чат с агентом: идеи тем, ответы про контент, переход в студию из ответа.
- Все настройки сохраняются в `localStorage`.

### 📅 Контент-план и архив
- Недельная сетка публикаций на 7 дней вперёд (включая сегодняшний день).
- Запланируйте материал на конкретный день одной кнопкой или заполните слот из архива.
- Архив сохранённых серий и постов, повторное открытие в студии.
- Фильтры по типу контента, отметка даты публикации.
- Черновики студий сохраняются автоматически и не теряются при перезагрузке страницы.

### 🔌 Движки генерации
- **Smart Engine** (по умолчанию) — встроенный офлайн-генератор, полностью учитывающий настройки персоны; работает без ключей.
- **OpenAI**, **Groq**, **OpenRouter** (любой OpenAI-совместимый endpoint) — ключ вводится в UI, хранится только локально,
  запросы идут напрямую из браузера. При ошибке автоматически используется встроенный движок.

## Технологии

React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · lucide-react · html-to-image (экспорт PNG) · canvas-confetti.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка в dist/
npm run preview
```

## Структура

```
src/
├── components/
│   ├── stories/       Студия сториз: канвас телефона, редактор слайда, таймлайн
│   ├── posts/         Студия постов: превью соцсетей, генератор хуков
│   ├── planner/       Контент-план и архив
│   ├── agent/         Чат с ИИ-агентом
│   ├── PersonaModal   Кастомизация агента
│   ├── ApiKeyModal    Выбор движка и API-ключ
│   └── Navbar         Навигация и переключатель агентов
├── context/AppContext Персоны, черновики, архив, настройки, чат
├── data/              Архетипы, темы, формулы, генератор
└── types/             Типы домена
```

## Приватность

Ключи API, настройки агентов, черновики и архив хранятся только в браузере (`localStorage`) и никуда не отправляются,
кроме запросов к выбранному вами провайдеру LLM. Сброс данных — очистка LocalStorage для домена приложения.
