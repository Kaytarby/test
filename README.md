# ФинПульс — лендинг о личных финансах

Одностраничный лендинг вымышленного сервиса **ФинПульс**: 41 банк и брокер
в одной картине, лимиты, цели и короткий отчёт раз в неделю.

Собран на чистом HTML, CSS и JavaScript — без сборки, фреймворков и зависимостей.

**Демо:** https://finpulse-landing.vercel.app

## Скилл

Проект сделан по скиллу [`landing-page-design`](.claude/skills/landing-page-design/SKILL.md)
из репозитория [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills)
(MIT). Он лежит в `.claude/skills/landing-page-design/` и читается агентами
(Claude Code, Cursor, Codex, Windsurf) как правила.

Что из скилла применено:

- **Стратегия:** один оффер, одна аудитория, одно действие; копирайт по формулам
  «{результат} без {боли}»; доказательства рядом с утверждением; риск-реверс
  (бесплатный тариф, 14 дней, без карты, отмена в один клик).
- **Типографика:** только Manrope (+ Geist Mono для цифр и меток, где моноширинный
  функционально нужен), веса до 700, без курсива, все размеры на шкале Tailwind,
  `text-wrap: balance` для заголовков и `pretty` для текста.
- **Сетка:** отступы и радиусы только из шкалы скилла, формула вложенного радиуса,
  плоские поверхности без градиентов, обводка по всему контуру.
- **Hero:** градиент только на тексте заголовка `#FFFFFF → #9B9B9B`, ограничение
  строки 680px и переносы по смыслу.
- **Иконки:** Phosphor (regular), 12 символов в SVG-спрайте.
- **Движение:** одна кривая `cubic-bezier(0.22, 1, 0.36, 1)`, анимация только
  `transform`/`opacity`, `IntersectionObserver` вместо скролл-листенеров,
  полное уважение `prefers-reduced-motion`.
- **Обязательный блок tagline reveal (B11):** манифест, где слова проявляются
  по мере пересечения триггерной линии.
- **Ship-требования:** 404, документы, cookie-плашка, валидация формы, skip-link,
  favicon, OG-теги, alt/aria, семантическая разметка.

## Анимации

| Где | Что происходит |
|---|---|
| Hero | строки заголовка выезжают из «шторки», остальное появляется каскадом |
| Hero | карточка дашборда наклоняется за курсором, параллакс при скролле |
| Hero | график рисуется по контуру, затем проявляется площадь и точка |
| Hero | вращающийся штамп, плавающие чипы, магнитная кнопка |
| Манифест | слова загораются по одному при пересечении линии |
| Счета | шесть карточек «разлетаются» и собираются в столбец при входе в кадр |
| Как работает | sticky-сцена: шаги сменяют друг друга по прогрессу скролла, экраны внутри меняются |
| Тарифы | тумблер с перетекающим бегунком и сменой цен |
| FAQ | аккордеон на `grid-template-rows` без скачков высоты |
| Везде | курсор-кольцо с инерцией и blend-mode, прогресс чтения, бегущие строки |

## Структура

```
index.html            — разметка лендинга
legal.html            — политика, условия, безопасность, обработка данных
404.html              — брендированная страница 404
assets/styles.css     — дизайн-токены и стили
assets/app.js         — вся интерактивность
assets/fonts/         — Manrope и Geist Mono, подмножества cyrillic/latin/latin-ext
assets/og.png         — обложка 1200×630 для соцсетей
assets/favicon.svg
site.webmanifest
vercel.json           — заголовки безопасности и кэш статики
.claude/skills/       — установленный скилл
```

## Локальный запуск

```bash
python3 -m http.server 3000
# открыть http://localhost:3000
```

## Деплой

Статический сайт: сборки нет, публикуется корень репозитория
(`outputDirectory: "."`, install и build — no-op команды, чтобы Vercel не искал `package.json`).

```bash
vercel --prod
```

или **Redeploy** в панели Vercel.

## Важно

Демонстрационный проект. Сервис, тарифы, отзывы, банки и рыночные показатели вымышлены
и не являются инвестиционной рекомендацией.
